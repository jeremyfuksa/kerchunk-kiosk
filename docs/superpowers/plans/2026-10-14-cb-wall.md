# CB Wall ("the dial") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In CB mode the kiosk wall drops the map and shows a CB-only layout: a big channel readout, a band "dial" with fading activity ticks, and a "Heard on CB" log.

**Architecture:** A `.cbStage` class on the existing dashboard page (no new page). Mode comes from the existing `/api/status` poll. A pure model (`cbDial.ts`) folds WS events and one history backfill into per-channel last-heard times and a log. A pure view (`cbView.ts`) turns that into a view object and an HTML string. `dashboard.ts` only wires the two to the DOM and paints when the view key changes. The map gets a reversible `pause()`/`resume()` (new `GlassLayer.setPaused`) so the hidden map does no draw or poll work.

**Tech Stack:** TypeScript (ESM, `.js` import extensions, `strict` + `noUncheckedIndexedAccess`), vanilla DOM (no framework), vitest (node environment, no DOM), zod config schema.

**Spec:** `docs/superpowers/specs/2026-10-14-cb-wall-design.md`

## Global Constraints

- Work in the worktree `/home/kiosk/kerchunk-cb` on branch `feat/cb-wall` (already rebased on `main`, which has CB mode from PR #296). All commands run from `/home/kiosk/kerchunk-cb/kiosk` unless stated.
- **Stage files by path. Never `git add -A` / `git add .`**: `kiosk/node_modules` in this worktree is a symlink to the live checkout's, and committing it once deleted the live `node_modules`.
- Vanilla TS only, no frontend framework. Icons only from `lucide-static` (this plan needs none).
- Relative imports carry `.js` even from `.ts`. Indexed access is `T | undefined`, so handle it.
- Every dashboard CSS selector is prefixed `html[data-page="dashboard"]`. New sizes become tokens in `src/frontend/tokens.css` (`--kc-k-*`); colours use existing `--kc-*` tokens only.
- **Thermal:** no standing animation, no CSS `transition`/`animation` on the CB stage, no `backdrop-filter`, no full-screen overlay. Paint only on CB events and the `stepTickMs` tick.
- **Sequential fetches:** every dashboard fetch goes through the dashboard poller (`poller.poll`/`poller.request`). The appliance deadlocks on concurrent requests.
- Channel names: `{6:"Super Bowl", 9:"Emergency", 19:"Highway"}`. Fade steps `[2, 10, 20, 30]` minutes, step tick `60000` ms, log rows `5`.
- External API consumer (jeremyfuksa.com) reads `/api/status`, `/api/logs` and `/api/weather`. Do not change those shapes.

## Review Focus

1. **Page loads while already in CB mode, before the map has mounted.** The map handle arrives later and must be paused on arrival, not left drawing. (Task 5, step 5 wiring; proven in Task 6 step 4.)
2. **Weather break-in from CB and back** (`cb` → `weather` → `cb`). The stage leaves and returns, history is re-requested, and the step interval is not duplicated. (Task 5, `setCbStage` is idempotent; Task 6, step 4 runs it on the wall.)
3. **Backend restart or retune mid-transmission:** no `release` ever arrives, so the log row must not stay on "now". `cbReduce` clears `open` on any `status` event. (Task 3 test.)
4. **History rows that aren't CB** (a frequency off the CB table, `closecall`/`alert` kinds). They are ignored, not plotted on channel 1. (Task 3 test.)
5. **Names containing markup** (an operator-entered `cb.names` value). Escaped in the log and the readout. (Task 4 test.)

Also, outside this branch: the unmerged `feat/glass-lightning` adds a lightning poll in `map.ts`. When it is integrated (Task 6) that poll needs the same `!paused` guard as the radar poll.

```ts
/** Built-in channel names (operator: 6 "Super Bowl", 9 "Emergency",
 *  19 "Highway"). config.cb.names replaces the whole map. */
export const CB_NAMES_DEFAULT: Readonly<Record<string, string>> = { "6": "Super Bowl", "9": "Emergency", "19": "Highway" };

/** The CB channel number at exactly this frequency, or null (history rows
 *  carry only freq). */
export function cbNumberForFreq(freqHz: number): number | null {
  for (const n of CB_ALL) if (CB_FREQ_HZ[n] === freqHz) return n;
  return null;
}

/** "CB 19 · Highway", or "CB 14" for an unnamed channel. */
export function cbLabel(n: number, names: Readonly<Record<string, string>> = CB_NAMES_DEFAULT): string {
  const name = names[String(n)];
  return name ? `CB ${n} · ${name}` : `CB ${n}`;
}

/** The CB-mode channel set. Always audible: picking CB mode is deliberate
 *  listening, so the family speaker gate doesn't apply. No location — CB
 *  hits land in history but never on the map. */
export function cbChannels(numbers: readonly number[] = CB_ALL, names: Readonly<Record<string, string>> = CB_NAMES_DEFAULT): Channel[] {
  const out: Channel[] = [];
  for (const n of [...new Set(numbers)].sort((a, b) => a - b)) {
    const freq = CB_FREQ_HZ[n];
    if (freq === undefined) continue;
    out.push({ id: `cb_${n}`, freq, alphaTag: cbLabel(n, names), mode: "am", enabled: true, audible: true, tags: ["cb"] });
  }
  return out;
}
```

```ts
// CB wall (spec 2026-10-14 "the dial"): the pure model behind the CB stage.
// No DOM, no fetch — dashboard.ts folds WS events and one history backfill in,
// and cbView.ts draws from it.
import type { EngineEvent } from "../../backend/engine/ScannerEngine.js";
import { CB_FREQ_HZ, cbNumberForFreq } from "../../backend/config/cb.js";

export interface CbHeard { n: number; ts: number; durationMs: number | null }
export interface CbState {
  /** Channel number → when it was last heard (the close time once released). */
  lastHeard: Readonly<Record<number, number>>;
  /** Transmissions, newest first. */
  log: readonly CbHeard[];
  /** Open transmissions by engine channel id. */
  open: Readonly<Record<string, { n: number; ts: number }>>;
}
export const CB_EMPTY: CbState = { lastHeard: {}, log: [], open: {} };
/** A /api/history row, as far as the dial cares. */
export interface CbHistoryRow { ts: number; freq: number; kind?: string; durationMs?: number | null }

const LOG_CAP = 50;

export function cbNumberForId(channelId: string): number | null {
  const m = /^cb_(\d{1,2})$/.exec(channelId);
  const n = m ? Number(m[1]) : NaN;
  return n >= 1 && n <= 40 ? n : null;
}

// Dial ends: the band edges plus half a channel, so 1 and 40 sit off the rim.
const DIAL_LO = (CB_FREQ_HZ[1] ?? 26_965_000) - 5_000;
const DIAL_HI = (CB_FREQ_HZ[40] ?? 27_405_000) + 5_000;

/** Position across the dial, 0–1, at true frequency spacing (23 lands
 *  between 25 and 26, as it does on the air). */
export function dialX(freqHz: number): number {
  return Math.min(1, Math.max(0, (freqHz - DIAL_LO) / (DIAL_HI - DIAL_LO)));
}

export type FadeStep = 0 | 1 | 2 | 3 | 4;

/** 4 = just heard … 1 = nearly faded, 0 = plain. A step drops at each
 *  fadeStepsMin mark (display.cb.fadeStepsMin, minutes, ascending). */
export function tickStep(lastHeard: number | undefined, now: number, fadeStepsMin: readonly number[]): FadeStep {
  if (lastHeard === undefined) return 0;
  const ageMin = (now - lastHeard) / 60_000;
  for (let i = 0; i < 4; i++) if (ageMin < (fadeStepsMin[i] ?? 0)) return (4 - i) as FadeStep;
  return 0;
}

export function cbReduce(s: CbState, ev: EngineEvent): CbState {
  if (ev.type === "active") {
    const n = cbNumberForId(ev.channel.id);
    if (n === null) return s;
    return {
      lastHeard: { ...s.lastHeard, [n]: ev.ts },
      log: [{ n, ts: ev.ts, durationMs: null }, ...s.log].slice(0, LOG_CAP),
      open: { ...s.open, [ev.channel.id]: { n, ts: ev.ts } },
    };
  }
  if (ev.type === "release") {
    const o = s.open[ev.channelId];
    if (!o) return s;
    const open = { ...s.open };
    delete open[ev.channelId];
    return {
      lastHeard: { ...s.lastHeard, [o.n]: ev.ts },
      log: s.log.map((r) => (r.n === o.n && r.ts === o.ts ? { ...r, durationMs: ev.ts - o.ts } : r)),
      open,
    };
  }
  // An engine state change (restart, a retune into another mode) ends every
  // transmission without release events — never leave a row stuck on "now".
  if (ev.type === "status") return Object.keys(s.open).length ? { ...s, open: {} } : s;
  return s;
}

/** Fold a /api/history?tag=cb backfill in: rows dedupe against what the live
 *  feed already logged (same channel + open time). */
export function cbSeed(s: CbState, rows: readonly CbHistoryRow[]): CbState {
  const seen = new Set(s.log.map((r) => `${r.n}:${r.ts}`));
  const lastHeard: Record<number, number> = { ...s.lastHeard };
  const add: CbHeard[] = [];
  for (const r of rows) {
    if (r.kind !== undefined && r.kind !== "active") continue;
    const n = cbNumberForFreq(r.freq);
    if (n === null || seen.has(`${n}:${r.ts}`)) continue;
    seen.add(`${n}:${r.ts}`);
    const durationMs = typeof r.durationMs === "number" ? r.durationMs : null;
    add.push({ n, ts: r.ts, durationMs });
    const end = r.ts + (durationMs ?? 0);
    if ((lastHeard[n] ?? -Infinity) < end) lastHeard[n] = end;
  }
  if (add.length === 0) return s;
  return { ...s, lastHeard, log: [...s.log, ...add].sort((a, b) => b.ts - a.ts).slice(0, LOG_CAP) };
}
```

```ts
// CB wall (spec 2026-10-14 "the dial"): CbState → what the stage shows, and
// the stage's markup. Pure: dashboard.ts rebuilds the DOM only when `key`
// changes and patches the meter + dB in place during a transmission.
import { CB_ALL, CB_CORE, CB_FREQ_HZ, cbLabel, cbNumberForFreq } from "../../backend/config/cb.js";
import { fmtFreq, esc } from "../lib/format.js";
import { dbText, segmentsLit } from "../faceplate/lcd.js";

import { dialX, tickStep, type CbState, type FadeStep } from "./cbDial.js";

export const CB_VIEW_DEFAULTS = { fadeStepsMin: [2, 10, 20, 30], stepTickMs: 60_000, logRows: 5 };

export interface CbViewInput {
  cb: CbState;
  now: number;
  /** The dashboard's nowPlaying frequency (the audible channel), if any. */
  liveFreq: number | null;
  error: string | null;
  muted: boolean;
  /** Channel numbers the scanner is listening to (config.cb.channels). */
  monitored: readonly number[];
  names: Readonly<Record<string, string>>;
  fadeStepsMin: readonly number[];
  logRows: number;
  fmtTime?: (ts: number) => string;
}
export interface CbReadout {
  state: "live" | "idle" | "never" | "error";
  meta: string;
  /** Right-hand meta: "Last heard 5:39 PM", "Muted", or "" (live shows dB). */
  metaRight: string;
  num: string;
  name: string;
  freq: string;
}
export interface CbTick { n: number; x: number; core: boolean; monitored: boolean; step: FadeStep; label: boolean }
export interface CbLogRow { label: string; when: string; live: boolean }
export interface CbView { key: string; readout: CbReadout; ticks: CbTick[]; needleX: number | null; log: CbLogRow[] }

const clock = (ts: number): string => new Date(ts).toLocaleTimeString([], { hour: "numeric", minute: "2-digit" });

/** "0:41", "2:05". */
export function fmtDur(ms: number): string {
  const s = Math.max(0, Math.round(ms / 1000));
  return `${Math.floor(s / 60)}:${String(s % 60).padStart(2, "0")}`;
}

const freqOf = (n: number): number => CB_FREQ_HZ[n] ?? 0;

export function cbView(i: CbViewInput): CbView {
  const t = i.fmtTime ?? clock;
  const core = CB_CORE as readonly number[];
  const name = (n: number): string => i.names[String(n)] ?? "";
  const liveN = i.liveFreq === null ? null : cbNumberForFreq(i.liveFreq);
  const listening = `CB only · Listening on ${i.monitored.length} channels`;
  const last = i.cb.log[0];

  let readout: CbReadout;
  if (i.error) {
    readout = { state: "error", meta: "Radio error", metaRight: "", num: "", name: friendlyError(i.error), freq: "" };
  } else if (liveN !== null) {
    readout = { state: "live", meta: "CB only · AM · Live", metaRight: i.muted ? "Muted" : "", num: String(liveN), name: name(liveN), freq: fmtFreq(freqOf(liveN)) };
  } else if (last) {
    readout = { state: "idle", meta: listening, metaRight: `Last heard ${t(i.cb.lastHeard[last.n] ?? last.ts)}`, num: String(last.n), name: name(last.n), freq: fmtFreq(freqOf(last.n)) };
  } else {
    readout = { state: "never", meta: listening, metaRight: "", num: "", name: "", freq: "" };
  }

  const ticks: CbTick[] = CB_ALL.map((n) => {
    const step: FadeStep = liveN === n ? 4 : tickStep(i.cb.lastHeard[n], i.now, i.fadeStepsMin);
    const isCore = core.includes(n);
    return { n, x: dialX(freqOf(n)), core: isCore, monitored: i.monitored.includes(n), step, label: isCore || n === 1 || n % 5 === 0 || step >= 3 };
  });

  const openKeys = new Set(Object.values(i.cb.open).map((o) => `${o.n}:${o.ts}`));
  const log: CbLogRow[] = i.cb.log.slice(0, i.logRows).map((r) => {
    const live = openKeys.has(`${r.n}:${r.ts}`);
    const when = live ? "now" : r.durationMs === null ? t(r.ts) : `${t(r.ts)} · ${fmtDur(r.durationMs)}`;
    return { label: cbLabel(r.n, i.names), when, live };
  });

  const needleX = liveN === null ? null : dialX(freqOf(liveN));
  const key = JSON.stringify([readout, ticks.map((k) => `${k.n}.${k.step}.${+k.monitored}.${+k.label}`), needleX, log]);
  return { key, readout, ticks, needleX, log };
}

const pct = (x: number): string => `${(x * 100).toFixed(2)}%`;

export function cbHtml(v: CbView, signalDb: number | null): string {
  const r = v.readout;
  const lit = r.state === "live" ? segmentsLit(meterFill(signalDb), METER_SEGMENTS) : 0;
  const seg = Array.from({ length: METER_SEGMENTS }, (_, k) => `<i${k < lit ? ' class="on"' : ""}></i>`).join("");
  const right = r.state === "live" && !r.metaRight
    ? `<span class="kc-cb__db">${esc(dbText(signalDb))}</span>`
    : `<span>${esc(r.metaRight)}</span>`;
  const readout = `<div class="kc-cb__readout" data-state="${r.state}">`
    + `<div class="kc-cb__meta"><span>${esc(r.meta)}</span>${right}</div>`
    + (r.num ? `<div class="kc-cb__num">${esc(r.num)}</div>` : "")
    + `<div class="kc-cb__sub"><b>${esc(r.name)}</b><span>${r.freq ? `${esc(r.freq)} MHz` : ""}</span></div>`
    + `<div class="kc-cb__seg" aria-hidden="true">${seg}</div></div>`;
  const ticks = v.ticks.map((k) =>
    `<i class="kc-cb__tick${k.core ? " is-core" : ""}${k.monitored ? "" : " is-off"}" data-step="${k.step}" style="left:${pct(k.x)}"></i>`
    + (k.label ? `<b class="kc-cb__lab${k.core ? " is-core" : ""}${k.step >= 3 ? " is-hot" : ""}" style="left:${pct(k.x)}">${k.n}</b>` : ""),
  ).join("");
  const needle = v.needleX === null ? "" : `<i class="kc-cb__needle" style="left:${pct(v.needleX)}"></i>`;
  const rows = v.log.map((l) => `<div class="kc-cb__row${l.live ? " is-live" : ""}"><span>${esc(l.label)}</span><i>${esc(l.when)}</i></div>`).join("");
  return `<div class="kc-cb__tag">CB mode</div>${readout}`
    + `<section class="kc-cb__log"><h2>Heard on CB</h2>${rows}</section>`
    + `<div class="kc-cb__dial" aria-hidden="true"><div class="kc-cb__scale">${ticks}${needle}</div></div>`;
}
```

```ts
    names: CB_NAMES_DEFAULT as Readonly<Record<string, string>>,

      ...CB_VIEW_DEFAULTS,
      ...cfg.display?.cb,
    };
  }).catch(() => { /* defaults stand */ });

  function setCbStage(on: boolean): void {

    cbOn = on;

    cbEl.setAttribute("aria-hidden", String(!on));

      mapHandle?.pause();
      poller.request("cbHistory");
      cbTimer = setInterval(schedule, cbOpts.stepTickMs); // fade steps; paint skips if nothing moved

      if (cbTimer) { clearInterval(cbTimer); cbTimer = null; }
      cbKey = "";
      cbEl.innerHTML = "";
    }
    schedule();

  poller.poll("cbHistory", () => {
    if (!cbOn) return Promise.resolve();

      .catch(() => { /* the dial fills from live events */ });
```
