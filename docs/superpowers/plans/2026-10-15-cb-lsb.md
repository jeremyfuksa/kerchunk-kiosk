# CB 38 LSB Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In CB mode, channel 38 is demodulated as LSB, opens on real SSB voice, stays shut on an empty channel, and plays at a level matched to AM — plus a ppm correction for the scan SDR.

**Architecture:** `kerchunk-dsp` gains a third lane demod (`Demod::Lsb`): a per-lane `SsbDemod` (shift → decimate → low-pass → interpolate → shift back) whose output feeds the lane's power meter and, through `SsbLevel`, the speaker. LSB lanes squelch on sideband energy against their own floor (no quieting gate, out of the shared floor). Node maps `config.cb.modes` (`{"38":"lsb"}` default) onto CB channels, and plumbs `radios[].ppm` → `--ppm` and `scan.nativeSsbGainDb` → `--ssb-gain-db`.

**Tech Stack:** C++17 (kcdsp, FFTW, librtlsdr; in-house `check.hpp` test harness), TypeScript/Node ≥24 ESM, zod, vitest.

**Spec:** `docs/superpowers/specs/2026-10-15-cb-lsb-design.md`

## Global Constraints

- All commands run from `kiosk/` (`cd kiosk`). Native tests: `npm run test:native`. Node tests: `npm test`. Types: `npm run typecheck` (both tsconfigs). Full build: `npm run build`.
- ESM: relative TS imports carry `.js`. tsconfig is `strict` + `noUncheckedIndexedAccess`.
- C++: no `-ffast-math`; no allocation on the per-hop / per-poll path (reserve up front).
- Sideband: `SSB_LO_HZ` 300, `SSB_HI_HZ` 2850 below the dial; normalizer attack 5 ms / release 1000 ms; `SSB_GAIN` 0.5.
- `--ssb-gain-db` range [−30, 20], default 0. `--ppm` integer range [−200, 200], default 0.
- `config.cb.modes` default `{"38":"lsb"}`; `CB_SSB_HANG_MS` 1500; `cb.ssbOpenDb` absent = scanner `--open-db`.
- `radios[]` is boot-bound: a `ppm` change needs `sudo systemctl restart kerchunk-kiosk`.
- Two PRs: PR 1 native (Tasks 1–5, branch `feat/dsp-lsb`), PR 2 Node (Tasks 6–8, branch `feat/cb-lsb`, cut from `feat/dsp-lsb`). Do **not** merge PR 1 with `--delete-branch` while PR 2 targets it — rebase PR 2 onto `main` after PR 1 merges (memory: stacked PR + `--delete-branch` closes the child).
- The appliance is live: during Tasks 1–7 don't restart `kerchunk-kiosk`; one deploy + restart in Task 8.

## Review Focus

1. **A wide lane's threshold drifting because an LSB lane joined the group** — the AM channels around 38 must open exactly as before. Pinned by `scanner_lsb_floor_stays_out_of_the_shared_floor` (Task 2).
2. **A group with only LSB lanes** (e.g. `cb.channels: [38]`) — the shared floor is empty; the LSB lane must still open on its own floor, not silently never decide. Pinned by `scanner_lsb_lane_opens_on_energy_without_quieting` (only lane in the group, Task 2).
3. **Weak SSB station** (RF level 30 dB below a strong one) — must still be audible, not left 15 dB under the AGC's reach. Pinned by `ssb_level_normalizes_weak_and_strong` (Task 1) and `speaker_lsb_source_plays_the_real_part_not_the_discriminator` (Task 3, 0.01 amplitude).
4. **Squelch-tail hang on SSB** — syllable gaps must not chop a transmission; the hang override must apply to LSB lanes. Pinned by `scanner_lsb_honours_hang_ms` (Task 2) and `cbChannels` carrying `hangMs` 1500 (Task 6).
5. **The pre-existing all-40 fallback** — `cbChannels()` with no arguments (the `/api/test/tx` preview path) must now give 38 its LSB mode too, and every other channel stays AM. Pinned in Task 6's `cbChannels` test.

```cpp
// ---- SSB (LSB) lanes: CB 38 (spec docs/superpowers/specs/2026-10-15-cb-lsb-design.md).
// The lower sideband sits SSB_LO_HZ..SSB_HI_HZ below the dial. SsbDemod shifts its centre to DC,
// decimates by SSB_DECIM so the sharp channel filter is cheap, low-passes to half the sideband
// width, interpolates back to LANE_RATE and shifts back.
inline constexpr double SSB_LO_HZ = 300;
inline constexpr double SSB_HI_HZ = 2850;
inline constexpr double SSB_TRANSITION_HZ = 300;      // channel filter edge width, at SSB_RATE
inline constexpr int SSB_DECIM = 4;
inline constexpr int SSB_RATE = LANE_RATE / SSB_DECIM;   // 12.5 kHz
inline constexpr double SSB_AA_CUTOFF_HZ = 2500;      // decimate/interpolate low-pass (band is +-1275 Hz)
inline constexpr double SSB_AA_TRANSITION_HZ = 2000;
// Speaker level: SSB has no carrier or deviation to normalize against, so its audio follows RF
// level (~30 dB between stations, past the AGC's 15 dB). SsbLevel divides by a peak envelope.
inline constexpr double SSB_ENV_ATTACK_MS = 5;
inline constexpr double SSB_ENV_RELEASE_MS = 1000;
inline constexpr float SSB_GAIN = 0.5f;               // x --ssb-gain-db, into the AGC
```

```cpp
// LANE_RATE: its power is the squelch's in-band energy, its real part is the audio (via SsbLevel).
class SsbDemod {
 public:
  SsbDemod();

  void reset();

// SSB speaker level: Re(x) over a peak-tracking envelope of |x| (fast attack, slow release), so
// a weak and a strong station reach the AGC at the same level. Primes on the first sample.

  float step(cf x);
  void reset() { primed_ = false; }

  float env_ = 0;
  bool primed_ = false;
```

In `src/demod.cpp`, extend the anonymous namespace and add the definitions:

```cpp
const double kSsbW = 2 * M_PI * ((SSB_LO_HZ + SSB_HI_HZ) / 2) / LANE_RATE;   // sideband centre -> DC
const float kSsbAtt = (float)(1 - std::exp(-1.0 / (SSB_ENV_ATTACK_MS / 1000 * LANE_RATE)));
const float kSsbRel = (float)(1 - std::exp(-1.0 / (SSB_ENV_RELEASE_MS / 1000 * LANE_RATE)));
std::vector<float> ssb_aa() { return design_lowpass(LANE_RATE, SSB_AA_CUTOFF_HZ, SSB_AA_TRANSITION_HZ); }
std::vector<float> ssb_ch() { return design_lowpass(SSB_RATE, (SSB_HI_HZ - SSB_LO_HZ) / 2, SSB_TRANSITION_HZ); }
```

```cpp
SsbDemod::SsbDemod()
    : dec_i_(ssb_aa()), dec_q_(ssb_aa()), ch_i_(ssb_ch()), ch_q_(ssb_ch()), int_i_(ssb_aa()), int_q_(ssb_aa()) {}

cf SsbDemod::step(cf x) {
  // The sideband is centred (LO+HI)/2 below the dial: rotate up by that much so it sits at DC.
  const cf rot = std::polar(1.0f, (float)ph_);
  ph_ += kSsbW;
  if (ph_ > M_PI) ph_ -= 2 * M_PI;
  const cf s = x * rot;
  const float di = dec_i_.step(s.real()), dq = dec_q_.step(s.imag());
  cf in{0, 0};
  // Every SSB_DECIM-th sample through the channel filter; the rest are zero-stuffed for the
  // interpolator, so x SSB_DECIM restores the level.
  if (k_ == 0) in = cf(ch_i_.step(di), ch_q_.step(dq)) * (float)SSB_DECIM;
  k_ = (k_ + 1) % SSB_DECIM;
  const cf u(int_i_.step(in.real()), int_q_.step(in.imag()));
  return u * std::conj(rot);   // back to where it was below the dial
}

void SsbDemod::reset() {
  dec_i_.reset(); dec_q_.reset(); ch_i_.reset(); ch_q_.reset(); int_i_.reset(); int_q_.reset();
  ph_ = 0;
  k_ = 0;
}

float SsbLevel::step(cf x) {
  const float m = std::abs(x);
  if (!primed_) {
    env_ = m;
    primed_ = true;
  } else {
    env_ += (m > env_ ? kSsbAtt : kSsbRel) * (m - env_);
  }
  return env_ > 1e-12f ? x.real() / env_ : 0.f;
}
```
